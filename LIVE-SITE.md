### 2. Local Development
Run `START-ALL.bat` to start both servers locally:
- Portfolio: http://localhost:3000
- CMS: http://localhost:3333

### 3. Deploying Updates
After making code changes:
```bash
npm run build
vercel --prod
```

## 🎨 Adding New Projects

1. **Open CMS**: https://mousetechnologies.sanity.studio/
2. **Click**: "Project" → "Create"
3. **Fill in**:
   - Title (e.g., "Wedding Invitation Design")
   - Slug (auto-generated from title)
   - Category (Church Designs, Social Media, Branding, Business Flyers)
   - **Thumbnail**: Main project image
   - **Images**: All project images (drag & drop)
   - **Problem**: What challenge did the client have?
   - **Solution**: How did your design solve it?
   - **Process**: Step-by-step approach (4 steps recommended)
   - **Results**: What impact did your design have?
   - Year & Client name
4. **Click**: "Publish"

Done! Project appears on your live site within seconds.
